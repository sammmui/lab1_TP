# Changelog

## [1.0.0] - 2026-11-18
### Added
- Формальна граматика SIPL у форматі Lark (`grammar/sipl.lark`).
- Парсер із побудовою типізованих AST-вузлів та `SourceSpan`.
- Інтерпретатор із захистом від нескінченних циклів.
- CLI-інтерфейс (`parse`, `check`, `run`, `trace`, `--json`).
- Тестовий набір із 20 позитивних та негативних тестів (`run_tests.py`).
- Генератор візуалізацій Parse Tree та AST (`visualize.py`).
